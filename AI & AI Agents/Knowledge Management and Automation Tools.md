# Knowledge Management and Automation Tools

The supplied list describes tools for collecting knowledge, getting AI assistance, and automating work across apps.

1. [Mem0](https://mem0.ai) — Long-term memory for AI across conversations. Its related GitHub project, [mem0ai/mem0](https://github.com/mem0ai/mem0), had **66,925 stars** and an **Apache License 2.0** when checked on 10 October 2026. See [AI Agent Memory Repositories](AI%20Agent%20Memory%20Repositories.md).
2. [NotebookLM](https://notebooklm.google) — Turn files and notes into a research assistant.
3. [Readwise Reader](https://readwise.io/read) — Collect articles, PDFs, highlights, and knowledge in one place.
4. [Obsidian](https://obsidian.md) — Store a local personal knowledge base and link notes together.
5. [n8n](https://n8n.io) — Automate workflows between notes, AI, email, documents, and apps. Its GitHub project, [n8n-io/n8n](https://github.com/n8n-io/n8n), had **206,869 stars** and uses a **Sustainable Use License**, with a separate Enterprise License for `.ee` files ([license](https://github.com/n8n-io/n8n/blob/master/LICENSE.md)), checked 10 October 2026. See [Build and Operate Web Applications with GitHub Repositories](Build%20and%20Operate%20Web%20Applications%20with%20GitHub%20Repositories.md).
6. [Anthropic knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) — Role-based plugins for Claude Cowork and Claude Code across areas such as sales, customer support, product management, marketing, legal, finance, and data. It had **29.8k stars** and an **Apache License 2.0**, checked 15 October 2026. See [GitHub Repositories for AI Agents and Developer Work](GitHub%20Repositories%20for%20AI%20Agents%20and%20Developer%20Work.md).

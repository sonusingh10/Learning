## Self-hosted API router

[tashfeenahmed/freellmapi](https://github.com/tashfeenahmed/freellmapi) — **35,238 stars**, checked 14 October 2026 · **MIT License**. Provider quotas and free-tier terms can change; this tool does not guarantee a permanent amount of free usage.

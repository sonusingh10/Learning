# AI Image and Voice Models

Model and project links from the supplied resource list. Counts checked on **18 October 2026**.

## Image generation and editing

- [QwenLM/Qwen-Image-2.1](https://github.com/QwenLM/Qwen-Image-2.1) — **2.0k GitHub stars** · **Qwen Research License Agreement**. The model supports text-to-image generation and image editing; its Turbo variant uses an 8-step schedule. The license permits non-commercial use only; commercial use requires a separate license ([license](https://github.com/QwenLM/Qwen-Image-2.1/blob/main/LICENSE)).

## Speech generation

- [Fish Audio Drama 3](https://huggingface.co/fishaudio/drama-3) — Hugging Face text-to-speech model for multi-character scenes and long-form content, with multi-speaker generation, voice cloning, and natural-language control. Hugging Face showed 8.19k downloads and 616 likes when checked 18 October 2026.
- **License:** Fish Audio Community License. Research and non-commercial use are allowed; commercial use is limited by an annual revenue threshold, and offering the model as a hosted speech-generation service requires a separate written license. The terms also restrict non-consensual voice imitation ([license](https://huggingface.co/fishaudio/drama-3/blob/main/LICENSE)).

The Hugging Face entry is a model resource rather than a GitHub repository, so it is not included in the project-wide GitHub star ranking.

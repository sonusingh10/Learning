# Open-Source Video Editors and Tools

This note collects GitHub video-editing projects from supplied lists. Concat was checked on **18 October 2026**; earlier entries retain their recorded check dates. Stars marked `~` are rounded values as displayed by GitHub.

| Repository | Stars | License type | Why it exists |
|---|---:|---|---|
| [LosslessCut](https://github.com/mifi/lossless-cut) | ~44.4k | GNU General Public License v2.0 (GPL-2.0) | Quickly trim and edit video, audio, and subtitles through an FFmpeg-based interface, with lossless cuts where supported. |
| [Blender](https://github.com/blender/blender) | ~20.8k | GNU General Public License v3.0; individual files may use different compatible licenses | Create 3D content across modeling, animation, rendering, compositing, and video editing. This GitHub repository is Blender's official mirror. |
| [Shotcut](https://github.com/mltframework/shotcut) | ~15.4k | GNU General Public License v3.0 (GPL-3.0) | Provide a cross-platform video editor built with Qt and MLT. |
| [Palmier Pro](https://github.com/palmier-io/palmier-pro) | ~14.5k | Historical source through v0.7.6 is GPLv3; later binaries are proprietary. | Provide a macOS video editor with built-in AI generation and MCP support for agents. |
| [Editly](https://github.com/mifi/editly) | ~5.5k | MIT License | Create videos programmatically from clips, images, audio, and titles, with transitions and a JavaScript API. |
| [jub0t/Concat](https://github.com/jub0t/Concat) | 8.5k (18 Oct 2026) | GNU Affero General Public License v3.0 (AGPL-3.0) | Provide a free, local-first video editor for multiple platforms, with a JSON-RPC API and MCP support for scripts and AI agents. |

**License note:** Palmier Pro is not fully open source in its current releases: the repository says source through v0.7.6 is available under GPLv3, while later binaries are proprietary. Also, Editly is a code-driven editing tool, and Blender is a broader 3D creation suite with a built-in video editor.

## Collection notes

- Resource descriptions are concise guides, not endorsements. Confirm current pricing, access, licensing, and availability on the linked source.
- Some items were captured from supplied posts; when a claim has not been checked independently, the note says so.
- Star totals change. The ranking records check dates and preserves earlier dates for older entries.
- The interactive [MCP explainer](AI%20%26%20AI%20Agents/MCP%20Explained/index.html) is available as a standalone page in the AI category.

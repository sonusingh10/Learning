# Contributing resources to this library

Use the category guides in the root [README](README.md) to find the right place. Keep notes concise, useful, and linked to primary sources.

## For a GitHub project

- Check whether it is already present before adding it.
- Record the canonical repository URL, current public star count and check date, declared license, and why the project exists.
- Record mixed, custom, or missing license information precisely.
- Add the repository to the project-wide ranked list, the relevant category’s `GitHub Repositories.md` table, and its topic note. Keep the canonical link, stars and check date, license, and purpose consistent in each place.
- If creating a new category, add its repository table and link it from the category guide.

## For a website, course, book, or other resource

- Add a direct link and a plain-language description of what it helps with.
- Put it in the existing category that fits best. If none fits, create a new category guide and add it to the root directory.
- Update the category `README.md` and root `README.md` when you create a file or category.
- Note when pricing, access, availability, or other changeable details were checked. Attribute claims from social posts to the supplied post unless independently verified.

# Learn Coding Through Games and Interactive Labs

A categorized collection of game-based learning sites, interactive labs, and challenges. Descriptions reflect the supplied posts and have not all been independently checked. The Docker and Kubernetes game repository's stars and license were checked on **14 October 2026**.

## Git, Linux, containers, and DevOps

- **Git:** [Oh My Git!](https://ohmygit.org) — See Git operations and branches visually; the post highlights learning what rebase does.
- **Git:** [Learn Git Branching](https://learngitbranching.js.org) — Practice Git branches and commands with a visual interface.
- **Linux:** [OverTheWire Wargames](https://overthewire.org/wargames/) — Learn security and Linux skills through command-line challenges.
- **Kubernetes:** [K8s Games](https://k8sgames.com) — Practice deploying pods and troubleshooting clusters with kubectl.
- **Docker and Kubernetes:** [ericboy0224/learn-docker-and-k8s](https://github.com/ericboy0224/learn-docker-and-k8s) — Interactive, AI-driven game for learning Docker, Linux, networking, and Kubernetes; designed to run in Claude Code or Cursor. **493 stars** (14 Oct 2026); **license unspecified** in GitHub metadata and repository files.
- **SRE:** [SadServers](https://sadservers.com) — Troubleshoot broken Linux servers in hands-on scenarios.
- **DevOps strategy:** [DevOps Games](https://devops.games) — Explore DevOps decision-making through a management simulation.

## Cloud learning

- **AWS:** [AWS Cloud Quest](https://aws.amazon.com/training/digital/aws-cloud-quest) — Learn AWS through interactive cloud scenarios and labs.
- **Google Cloud:** [Google Skills](https://skills.google) — Find hands-on learning activities, labs, and badges.

## Cybersecurity and AI security

- **Beginner CTFs:** [picoCTF](https://picoctf.org) — Carnegie Mellon University's beginner-friendly capture-the-flag challenges.
- **Hands-on cybersecurity:** [TryHackMe](https://tryhackme.com) — Learn cybersecurity through interactive rooms and labs.
- **Prompt injection:** [Gandalf](https://gandalf.lakera.ai) — Test whether you can persuade an AI wizard to reveal a hidden password.
- **AI agent security:** [Agent Breaker](https://gandalf.lakera.ai/agent-breaker) — Practice attacking AI agents through tool abuse, memory tampering, and data poisoning.

## Programming and web development

- **Python and JavaScript:** [CodeCombat](https://codecombat.com) — Learn programming by controlling a game with code.
- **Many languages:** [CodinGame](https://www.codingame.com) — Solve coding challenges and control game characters with code.
- **HTML and CSS:** [Codepip](https://codepip.com) — Practice web development through coding games.
- **Mobile coding:** [SoloLearn](https://www.sololearn.com) — Learn and practice programming on mobile and web.
- **Complete beginners:** [Scratch](https://scratch.mit.edu) — Create interactive stories, games, and animations with block-based coding.

## SQL, data, and machine learning

- **SQL mystery:** [SQL Murder Mystery](https://mystery.knightlab.com) — Solve a fictional murder by querying a database.
- **SQL Island:** [SQL Island](https://sql-island.informatik.uni-kl.de) — Learn SQL through a text-adventure game.
- **Machine learning game:** [while True: learn()](https://store.steampowered.com/app/619150/while_True_learn/) — A puzzle game about machine learning and understanding a cat.
- **Neural networks:** [TensorFlow Playground](https://playground.tensorflow.org) — Adjust a neural network and see how its behavior changes interactively.

# Open-Source Tools and Alternatives

The supplied post is titled “10 GitHub repos that seem ‘illegal’ but are perfectly legal.” This note records the post's descriptions and comparisons. New and refreshed GitHub star counts below were checked on **23 October 2026**; older entries retain their earlier dates. Counts can change.

## Media and transcription

1. [yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp) — 196,547 stars. The post describes it as a video downloader for many platforms and compares it with YouTube Premium at $16 per month.
2. [openai/whisper](https://github.com/openai/whisper) — 110,262 stars. The post describes it as a tool for transcribing audio in 99 languages and compares it with Otter at $20 per month.

## Local AI and image generation

- [ollama/ollama](https://github.com/ollama/ollama) — 182,582 stars · MIT License. Helps users download and run language models locally and connect them to apps and agents.
- [open-webui/open-webui](https://github.com/open-webui/open-webui) — approximately 154.2k stars · Mixed: Open WebUI License with required branding preservation; prior contributions keep original terms. Provides a self-hosted AI interface for local and cloud models.
- [ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp) — approximately 130.7k stars · MIT License. Runs large language model inference efficiently in C/C++ across different hardware.
- [lllyasviel/Fooocus](https://github.com/lllyasviel/Fooocus) — 53,347 stars · GNU General Public License v3.0 (GPL-3.0). The supplied post describes it as a way to generate images on a local GPU and compares it with a $30 Midjourney plan.
- [mudler/LocalAI](https://github.com/mudler/LocalAI) — approximately 49.5k stars · MIT License. Serves local models across multiple modalities through compatible APIs on varied hardware.
- [janhq/jan](https://github.com/janhq/jan) — approximately 44.9k stars · Apache License 2.0. Desktop app for running AI models offline with local control and privacy.

## Analytics, productivity, design, and automation

5. [plausible/analytics](https://github.com/plausible/analytics) — 29,355 stars. Described as an open-source alternative to Google Analytics; the post says self-hosting costs $0 and compares it with company plans costing thousands per year.
6. [AppFlowy-IO/AppFlowy](https://github.com/AppFlowy-IO/AppFlowy) — 77,217 stars. Described as an open-source alternative to Notion; the post compares it with a $20-per-user Notion plan and claims self-hosting supports unlimited users.
7. [penpot/penpot](https://github.com/penpot/penpot) — 61.6k (checked 24 Oct 2026) stars. Described as an open-source alternative to Figma; the post compares it with Figma at $16 per editor and says Penpot can be self-hosted for free.
8. [n8n-io/n8n](https://github.com/n8n-io/n8n) — 206,869 stars. Described as an open-source automation tool; the post says Zapier Pro can cost hundreds per month and describes n8n as allowing unlimited automations.
9. [calcom/cal.diy](https://github.com/calcom/cal.diy) — 48,932 stars. Described as an open-source alternative to Calendly; the post compares it with Calendly Teams at $16 per user and says Cal.com is free for personal use. (The repository now redirects from `cal.com` to `cal.diy`.)
10. [bitwarden/server](https://github.com/bitwarden/server) — 20,252 stars. Described as an open-source alternative to 1Password, with a “very complete” free version.
